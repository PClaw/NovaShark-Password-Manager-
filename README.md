## 🦈 NovaShark – Secure and Ad-Free Password Manager

**NovaShark** is a **privacy-focused**, **completely offline**, and **ad-free** password manager developed for Android devices.
It allows users to store and manage all their passwords **securely and neatly in one place**.

The application **does not transmit any user data to servers** and **does not require an internet connection**.

---

## 🔐 Security Architecture

* 🔑 App access is protected by **PIN authentication**
* Stored data is secured using the **SHA-256 algorithm**
* All passwords are stored **locally on the user’s device**
* **No data is shared** with third parties

---

## ⚙️ Key Features

* 📱 **Offline operation** (no internet required)
* 🔐 Secure password storage for websites and applications
* ⚡ **Strong random password generator**
* 📋 One-tap copy functionality
* 🛡️ Password strength analysis
* 📝 Notes support
* 🌙 Dark cyber-themed interface
* 🚫 **No advertisements**

---

## 🛡️ Privacy Policy

* NovaShark **does not collect user data**
* Passwords are **never transferred outside the device**
* No ads, trackers, or analytics tools
* User privacy is a top priority
